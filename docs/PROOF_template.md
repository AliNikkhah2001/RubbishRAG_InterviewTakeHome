# PROOF.md — اثبات ۱ صفحه‌ای (همراه لاگ و نمودار)

## ۱) چرا جمع نمره خام شکست می‌خورد و RRF درست است؟
- توزیع BM25 (unbounded, ~0..20) با dense (۰..۱) قابل جمع نیست؛ دانس یا اسمی always wins.
- فرمول RRF: `score(d) = Σ 1/(k + rank_i(d))` با `k=60` — فقط رتبه مهم است نه مقدار.
- نمودار `plots/score_spread.png` خودتان: نشان دهید top-1 خام با RRF جابه‌جا می‌شود.

## ۲) جریمه طول BM25 و کف BM25+
- فرمول: `tf*(k1+1)/(tf+k1*(1-b+b*dl/avgdl))` — با `b=0.9` سند بلند له می‌شود.
- نمودار `plots/length_vs_bm25.png`: recall پاسخ‌های بلند vs کوتاه.

## ۳) اثر آلودگی کلیدواژه
- نمودار `plots/poison_vs_gold.png`: میانگین BM25 سند سمی vs سالم روی کوئری کلیدواژه‌ای.
- راه‌حل شما: جریمه تکرار + فیلتر اسلات. شناسه trace ها را ذکر کنید.

(حداکثر ۱ صفحه + ۲ نمودار. بدون probe واقعی = مردود.)
