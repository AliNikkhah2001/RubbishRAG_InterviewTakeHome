# RubbishRAG — مدیر ما می‌گه AI اینو ۱ دقیقه‌ای ساخته!

شما به‌عنوان مصاحبه‌شونده باید ثابت کنید اشتباه می‌کند: رفتارش را اندازه
بگیرید، خطاها را پیدا کنید، اصلاحش کنید — و برای هر ادعا trace و نمودار بیاورید.

## داده (همین فایل نمونه، کامل — آزادید بخوانید)
- `corpus/test.csv` با ستون‌ها: `Question | Category | BriefAnswer | Answer | Keyword`
- ~۴۴۰ ردیف فارسی اعتبارسنجی. `BriefAnswer` = پاسخ کوتاه، `Answer` = پاسخ کامل.
- دقت کنید: بانک‌ها، رتبه‌ها (`A1..E3`)، اشخاص (حقیقی/حقوقی)، مبالغ و تاریخ‌ها
  در سؤال و جواب پخش‌اند — و گاهی کل تفاوت دو ردیف، در همین‌هاست.

## چیزی که نباید باز کنید (کد شرافت)
- همه‌چیزِ `server/` (نقش API ریموت را دارد؛ در مصاحبه واقعی روی سرور ماست).
  به‌جای خواندن، پروب کنید: `rubbish bepar` و `POST /retrieve`.
  سهمیه ۱۰۰۰ فراخوانی، لاگ کامل — یافته‌ها باید از لاگ قابل بازتولید باشند.

## دستورات

> روی فورک خودتان کار کنید، نه روی ریپوی اصلی:
> `Fork` در گیت‌هاب → کلون فورک خودتان → `git checkout -b solution/<username>`
> → `git checkout candidate` (شاخه تکلیف) → پایتون 3.11 → `pip install -r requirements.txt`

```
python3 rubbish.py salam        # اجرای اول: نام/ایمیل/گیت‌هاب برای کارت گزارش
python3 rubbish.py bepar "رتبه C یعنی چی؟" --topk 5
python3 rubbish.py bench            # بنچ visible (۲۰ سؤال) → traces/metrics.json
python3 rubbish.py bekesh           # سه نمودار در plots/
python3 rubbish.py bastesh          # submissions/submission.zip را بفرستید
```

## تحویل
1. کد اصلاح‌شده `rubbish_rag/` (دکوراتورها را بازنویسی کنید، نه API ریموت را)
2. `docs/PROOF.md` (به‌ازای هر تغییر: علامت + پروب + نمودار + تصمیم)
3. `submissions/submission.zip` از `bastesh`
بنچ مخفی (~۱۷۰ سوال دیده‌نشده: بازنویسی‌ها، تنوع اسلات‌ها، ابهام، خارج‌توزیع).
حفظی‌جات پایین می‌ماند؛ حد نصاب: دقت بالای ۶۵٪ + دفاع ۳۰ دقیقه‌ای از traceها.
