# RubbishRAG — مدیر ما می‌گه AI اینو ۱ دقیقه‌ای ساخته!

شما به‌عنوان مصاحبه‌شونده باید ثابت کنید اشتباه می‌کند: خطاها را پیدا و اصلاح کنید.

## داده (همین فایل نمونه، کامل)
- `corpus/test.csv` با ستون‌ها: `Question | Category | BriefAnswer | Answer | Keyword`
- ~۴۴۰ ردیف فارسی اعتبارسنجی. `BriefAnswer` = پاسخ کوتاه، `Answer` = پاسخ کامل.
- لیست بانک‌ها: ملی، صادرات، تجارت، توسعه صادرات، ملت، سپه، ...
- رتبه‌ها: `A1..E3` (لاتین داخل متن فارسی!) — بازه ۲۵۰ تا ۹۰۰.

## چیزی که نباید باز کنید
- `server/_hidden_retriever.py` و `server/hidden_eval.json` نقش API ریموت را دارند.
  در مصاحبه واقعی روی سرور ما هستند. باز کردن آن‌ها = تقلب.
  فقط با CLI با آن‌ها حرف بزنید (سهمیه ۱۰۰۰ فراخوانی، لاگ کامل).

## خطاهایی که باید شکار کنید (۷ خطا)
1. **فیوژن غلط:** جمع نمره خام به‌جای RRF — دانس همیشه برنده است.
2. **BM25 با جریمه طول:** `b~0.9` بدون کف — پاسخ‌های بلند و معتبر می‌بازند.
3. **آلودگی کلیدواژه:** ۸ سند سمی با تکرار کلیدواژه که BM25 را فریب می‌دهد.
4. **OOD:** بازنویسی محاوره‌ای (`می‌شود→میشه`) و تایپی و نام بانک دیده‌نشده می‌شکند.
5. **چانکینگ:** تکه ۳۰۰ کاراکتری بدون سربرگ — `Category/Keyword` و `بانک/رتبه` گم می‌شود.
6. **ری‌رنکر:** فقط هم‌پوشانی لغوی — عاشق سند سمی است.
7. **ابهام:** هرگز سؤال clarifier نمی‌پرسد؛ بانک‌ها و رتبه‌ها را قاطی و توهم می‌سازد.

## اسلات‌های اجباری (کمبود = clarify)
`BANK | RANK | PERSONA(حقیقی/حقوقی) | DEBT(تسهیلاتی/مالیاتی/چک/محکومیت) | AMOUNT | TIME`
- `حقیقی/حقوقی` اجباری است (چک ۱۲٪ در برابر ۶٪، مالیات ۹٪ در برابر ۱۸٪).
- اعداد حیاتی‌اند: `۲۵۰/250`، `۵ سال`، `۲۴ ساعت`، `یک ماه`، آستانه `۲۵۰ هزار تومان`.
- نرمال‌سازی فارسی اجباری: ارقام `۰-۹/٠-٩→0-9`، `ي→ی`، `ك→ک`، نیم‌فاصله، محاوره.

## قرارداد خروجی (اتوماتیک نمره می‌گیرد)
```json
{"status": "answer", "brief": "...", "cites": [doc_id]}
{"status": "clarify", "question": "...؟", "options": ["تسهیلات", "مالیات"]}
```

## دستورات
```
python3 rubbish.py salam
python3 rubbish.py bepar "رتبه C یعنی چی؟" --topk 5
python3 rubbish.py bench            # بنچ visible (۲۰ سؤال) → traces/metrics.json
python3 rubbish.py bekesh           # سه نمودار در plots/
python3 rubbish.py bastesh          # submissions/submission.zip را بفرستید
```

## تحویل
1. کد اصلاح‌شده `rubbish_rag/` (دکوراتورها را بازنویسی کنید، نه API ریموت را)
2. `docs/PROOF.md` (اثبات ۱ صفحه‌ای + ۲ نمودار از لاگ خودتان)
3. `submissions/submission.zip` از `bastesh`
بنچ مخفی: ~۸۰ سؤال (holdout + جابه‌جایی اسلات + ابهام + تایپی). پاسخ حفظی ~۴۰٪، راه‌حل درست >۸۰٪.
