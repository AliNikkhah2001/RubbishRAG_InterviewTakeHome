🗑️ RubbishRAG

مدیر ما می‌گه AI اینو ۱ دقیقه‌ای ساخته! شما ثابت کنید اشتباه می‌کنه.

۱. داستان

یه سیستم RAG فارسی روی دانشنامه اعتبارسنجی (۳۳۰ سوال/جواب واقعی) که ظاهراً تمومه ولی فقط ~۴۰٪ روی بنچ visible جواب درست می‌ده. مدیر فکر می‌کنه AI تو ۱ دقیقه نوشته — شما باید ثابت کنید اشتباه می‌کنه. کمک هوش مصنوعی مجازه؛ کافی نیست.

۲. چی باید کنید

  1. فورک ریپوی ما روی گیت‌هاب.
  2. candidate برنچ رو چک‌اوت کنید (کد + دیتای کامل + ایویل رمزشده).
  3. solution/<username> برنچ بسازید.
  4. پایتون ۳.۱۱ نیازه (بایتکد رمزشده).
  5. pip install -r requirements.txt
  6. python3 rubbish.py salam — اجرای اول اسم/ایمیل/گیت‌هاب رو می‌پرسه.
  7. python3 rubbish.py bepar "رتبه C1 یعنی چی؟" --topk 5
  8. python3 rubbish.py bench — بنچ visible (۲۰ سوال با جواب).
  9. python3 rubbish.py bekesh — سه نمودار.
  10. python3 rubbish.py bastesh — کارنامه توی README چاپ می‌کنه + submission.zip.

۳. معماری (چی دارید)

corpus/test.csv → chunk (۳۰۰ کاراکتر) → POST /retrieve → hits {bm25,dense,fused}
→ rerank (تعداد کلمات مشترک) → resolve (همیشه جواب می‌ده)

۴ تا دکوراتور داره: @R.chunker @R.retriever @R.reranker @R.resolver. فایل rubbish_rag/pipeline.py رو بخونید — همه چی کوتاهه و TODO داره.

  • Chunker: ۳۰۰ کاراکتر برش، بدون سربرگ
  • Retriever: API ریموت — نمره‌ها رو برگردونده (bm25/dense/fused)
  • Reranker: بر اساس تعداد کلمات مشترک با کوئری
  • Resolver: همیشه جواب، هیچ‌وقت سوال clarify نمی‌پرسه

۴. نشانه‌ها (شروع‌کننده‌ها)

  • بعضی hits به‌نظر بی‌ربط می‌یان — چرا نمرشون بالاس؟
  • بعضی کوئری‌ها که فقط یه کلمه فرق دارن جواب یکسان می‌گیرن — کی درسته، کی قاطی کردن دو جواب مختلف؟
  • بعضی کوئری‌ها اصلاً جواب خوبی توی کورپوس ندارن — الان چی می‌شه و چی باید بشه؟
  • نمره‌های bm25/dense/fused برمی‌گردن — پلاتشون کنید قبل از تئوری.

۵. اسلات‌های مهم

توی این کورپوس، عوض شدن یه کلمه می‌تونه جواب رو عوض کنه:

  • بانک (ملی، صادرات، تجارت، ...)
  • رتبه (A1 تا E3)
  • شخص (حقیقی / حقوقی)
  • مبلغ و زمان (۲۵۰، ۵ سال، ۲۴ ساعت، ...)
  • نوع بدهی (تسهیلاتی، مالیاتی، چک، محکومیت)

۷. تنظیم سرور API (برای مصاحبه‌کننده)

برای حالت آنلاین (به‌جای local):

# install
pip install fastapi uvicorn

# run
uvicorn server.app:app --host 0.0.0.0 --port 8000

# Swagger UI at http://YOUR_IP:8000/docs

بعد از اجرا، به هر кандидат یه api_key بدید و توی server/_secrets.py اضافش کنید. کلید هر نفر محدود به ۱۰۰۰ کال. لاگ کامل توی traces/ ذخیره می‌شه.
