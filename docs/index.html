The Premise

You are handed a Persian RAG chatbot over a real credit-scoring knowledge base (330 QA pairs in corpus/test.csv). It looks finished and polished on the surface, but it only scores ~25–30% on the visible benchmark.

Your manager remarks: "AI built this in one minute — prove it wrong."

Generic LLM advice tuned for frontier models will not rescue you here: the bugs are embedded deeply inside the scoring formulas, length normalization, tokenization, poison documents, and ungrounded resolvers of this specific system. AI coding assistants are welcomed, but they are not sufficient without disciplined engineering.

The Challenge at a Glance

🔍 1. Probe & Measure

Use rubbish bepar and rubbish bekesh to extract BM25, dense, and fused scores. Inspect distributions before forming theories.

🛠️ 2. Fix Pipeline Stages

Override the decorator stages in rubbish_rag/: normalize Persian script, implement slot matching, penalize poison docs, and route ambiguous queries.

📊 3. Defend with Proof

Document each change in docs/PROOF.md with trace IDs from traces/trace.jsonl. Claims without empirical traces are invalid.

Quickstart (5-Minute Setup)

Work on a GitHub fork of this repository. Clone your fork and check out the candidate branch:

# 1. Clone your fork and create your working branch
git clone https://github.com/<YOUR-USERNAME>/RubbishRAG_InterviewTakeHome.git
cd RubbishRAG_InterviewTakeHome
git checkout -b solution/<your-github-username>

# 2. Install dependencies (Python 3.11 required)
pip install -r requirements.txt

# 3. Meet the system (first run records candidate identity)
python3 rubbish.py salam
python3 rubbish.py bepar "رتبه C1 یعنی چی؟" --topk 5
python3 rubbish.py bench      # Runs 20 visible questions -> traces/metrics.json
python3 rubbish.py bekesh     # Generates diagnostic plots in plots/
python3 rubbish.py ui         # (Bonus) Launches interactive Studio UI on :8000
python3 rubbish.py bastesh    # Stamps README report & packs submissions/submission.zip
⚠️ Honor Code: Sealed Server:
The server/ scoring module simulates an external API endpoint. You must interact with it through rubbish bepar and /retrieve. Do not reverse-engineer hidden query answers directly — all claims must stem from logged probes.
